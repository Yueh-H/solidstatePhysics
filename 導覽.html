🪤渲染陷阱（踩過的，務必記住）
  • <figure>／<svg> 區塊內部絕不可有空白行（marked 遇空行會中斷 HTML 區塊），要從行首第 0 欄開始，前後各空一行。
  • SVG <text> 內只能放 unicode，不可有 $ —— MathJax 不渲染 SVG 內的 $。
  • <details> 相反：標籤各佔一行，</summary> 後要空一行（內容當 markdown 解析），內部可正常用 $...$。
  • \boldsymbol 需 MathJax config 預載才不會變紅字。已預載：unit01/06/08/10、Kittel ch05/08/09/10、13 份考古詳解。其餘檔新增內容改用 \mathbf。
