# Kittel 習題詳解 + 加碼範例 — 共用寫作規格

你要為某一章寫一份 markdown，內含兩部分：**(A) 加碼範例題目**＋**(B) Kittel 該章課本習題的完整逐步解答**。對象：只有高中數學＋單變數微積分＋基本矩陣/向量、備考台大應物所資格考「固態物理導論」的人。

> 課本：C. Kittel《Introduction to Solid State Physics》8e。**重要**：手上的解答手冊（`../Kittel_解答手冊.md`）在 PDF→md 轉檔時把大量公式/圖換成 `==> picture omitted <==`，幾乎不可用——所以你要**自己把每題從頭算到尾、每步都寫出來**。

## 0. 鐵則
1. **繁體中文（台灣）**，嚴禁簡體。物理量/單位/人名用原文。
2. **專有名詞中英對照**：第一次出現「中文（English）」。
3. **完整、不跳步**：每題用 `**Step 1 / Step 2 / …**`，一步一個動作，禁止「易證/顯然/整理得」。最後答案用 `$$\boxed{...}$$`（含單位）。
4. **數字要對**：有數值的題目要代入常數算出數值並檢查單位與量級。
5. 數學用 MathJax `$...$`/`$$...$$`，寫完檢查成對。
6. **每題先給「中譯題目」**（把 Kittel 英文題目翻成中文，保留符號），再給解答。

## 1. 每章固定骨架

````markdown
<!-- Kittel 習題詳解：第X章 <中文名> -->

# Kittel 第X章 習題詳解 ＋ 加碼範例 — <中文名>（<English>）

> **這頁是什麼**：本章的「練習題庫＋完整解答」。先做 **加碼範例** 熱身，再把 **Kittel 課本習題** 全部練過。觀念見 [章節導讀](../Kittel章節導讀/chXX_*.html)、[單元學科](../../單元教學/unitXX_*.html)；歷年考題見 [逐題詳解](../../考古題/詳解/index.html)。

## 🔥 加碼範例題目（先熱身）
<3–4 個你自編的範例題（涵蓋本章必考計算），每題：題目（含數字）→ Step 逐步 → $$\boxed{答案}$$。難度由淺到深。>

## 📚 Kittel 第X章 課本習題 — 完整解答
<把 Kittel 該章 end-of-chapter Problems **每一題** 都做：>
### 習題 N：<題目英文小標的中譯>（Kittel Prob. X.N）
**題目**：<中譯，保留符號與給定數值>
**Step 1 …** → **Step 2 …** →（不跳步）
$$\boxed{答案}$$
> **重點**：<一句話這題在考什麼/常見陷阱>

## ✅ 本章計算題自我檢核
<5–8 條「你應該能獨立算出」的清單。>
````

## 2. 各章範圍（作者只負責自己那一章）
> Kittel 英文題目在 `../Kittel_原文.md`；解答手冊（殘缺、僅供對答案參考）在 `../Kittel_解答手冊.md`。**只讀你那章的行區間**（檔案很大，用 Read 的 offset/limit）。題目編號照 Kittel 原書。

每位作者的「題目起始行、解答手冊章節」寫在你的任務指示裡。Kittel 章次與我們單元的對應：
- ch01 晶體結構 = Kittel Ch1；ch02 倒晶格與繞射 = Ch2；ch03 晶體鍵結 = Ch3；
- ch04 聲子 = Ch4＋Ch5；ch05 自由電子費米氣體 = Ch6；ch06 能帶 = Ch7；
- ch07 半導體 = Ch8；ch08 磁性 = Ch11＋Ch12；ch09 超導 = Ch10；ch10 費米面與進階 = Ch9。

## 3. 交付
- 只輸出**一個檔**：`chXX_<名>.md`，Write 到 `solidstatePhysics/教材/Kittel習題詳解/`。
- **不要建 HTML**（主控統一產生）。
- 回報：檔名、行數、加碼範例幾題、Kittel 習題解了幾題（第幾題到第幾題）、`$$` 是否成對。
- 目標長度：依題數，通常 250–500 行。寧可詳盡，不要跳步。
