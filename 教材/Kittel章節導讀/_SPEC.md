# Kittel 章節對照導讀 — 共用寫作規格

你要為「**讀 Kittel 翻譯本時的對照導讀**」寫某一章的 markdown。對象:只有高中數學+單變數微積分+基本矩陣/向量、剛開始念固態物理的人。這份**不是重新教推導**（推導在 `../../單元教學/` 已有），而是**讀 Kittel 那一章時的「概念橋 + 術語速查地圖」**。

> 課本:C. Kittel《Introduction to Solid State Physics》8e 中文翻譯（`../Kittel_翻譯.html`）。翻譯是機器轉檔，含 `�`、`==> picture omitted <==` 等雜訊——你要做的就是把那一章「翻成人話、搭好概念橋」。

## 0. 鐵則
1. **繁體中文（台灣）**，嚴禁簡體。
2. **專有名詞中英對照**：第一次出現寫「中文（English）」。
3. **三層概念對應**是本篇核心：每個核心概念都要回答「高中學過什麼 → 大學普物的版本 → 本章固態物理把它變成什麼」。
4. **每個術語給一個具體範例**（數字或情境），不要只給定義。
5. 數學用 MathJax：行內 `$...$`、獨立式 `$$...$$`，寫完檢查成對。
6. **輕量**：每章目標 150–280 行。重在「對照、橋接、速查」，不在長推導（長推導連到單元教學）。

## 1. 每章固定骨架

````markdown
<!-- Kittel 章節導讀：第X章 <中文名>（<English>） -->

# Kittel 第X章 對照導讀 — <中文名>（<English name>）

## 🗺️ 這一章在講什麼（3–6 句白話）
<用白話講這章的主線：從什麼出發、要解決什麼、得到什麼結論。對齊 Kittel 該章的節次順序。>

| 高中你學過的 | 大學普物的版本 | 本章固態物理變成 |

| …（5–9 列，涵蓋本章核心概念） | | |

## 🔑 專有名詞 × 範例（速查）
<該章 6–12 個關鍵術語。每個用 <details> 就地展開：>
<details>
<summary><b>▸ 中文（English）</b></summary>

**範例**：一個具體數字或情境（例如「sc 填充率 $=\pi/6\approx0.52$」）。

## 🔗 延伸

- 練歷年題：[逐題詳解](../../考古題/詳解/index.html)
````

## 3. 交付
- 只輸出**一個檔**：`ch0X_<名>.md`，用 Write 寫到 `solidstatePhysics/教材/Kittel章節導讀/`。
- 不要建 HTML（主控統一產生）。
- 回報：檔名、行數、`$$` 是否成對（`grep -o '\$\$' 檔 | wc -l` 取偶數）。
