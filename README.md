# 固態物理導論 — 備考資料夾

NTU 應用物理所博士班資格考「固態物理導論」備考素材。**目標:2027 年初資格考。**

## 怎麼用(備考路線)

1. **先看 → [`考古題/單元整理.md`](考古題/單元整理.md)** ★最重要
   歷年(2013–2025)考題依 Kittel 章節分 10 單元,含**出題頻率表**、各單元**必背公式**、
   **近年四段式固定題型**。先用它抓優先序。
2. **練題 → [`考古題/歷年原卷/`](考古題/歷年原卷/)** 13 份固態原卷(`固態物理導論_<年>.md`)。
3. **查觀念 → [`教材/`](教材/)** Kittel 原文/翻譯、講義、林盛煇課本、蕭智仁簡報、解答手冊。
