② 布拉格定律 ＋ Ewald 球（Bragg / Ewald）

左側：Ewald 作圖——入射波向量 k_in 末端在原點，球半徑 2π/λ； 倒晶格點 G 落在球上 ⇒ 繞射。右側：布拉格 2 d sinθ = n λ 是否滿足。

參數

λ 愈小 → Ewald 球愈大 → 更容易碰到倒晶格點
倒晶格間距 b = 2π/a；a 愈大 → 倒空間點愈密
布拉格：2 d sinθ = n λ ，此處 d = a（示意 1D 面距） Laue / Ewald：k_out − k_in = G ，|k| = 2π/λ 倒晶格（1D 示意）：G_h = h · (2π/a)，h = 0, ±1, ±2…
2D 示意：水平為倒空間 q_x。真實 3D Ewald 是球面；此處用圓截面建立 Δk=G 直覺。
